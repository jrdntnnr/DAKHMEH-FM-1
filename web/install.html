Install DAKHMEH

دخمه · desert instruments and maqam tuning for the M-VAVE FM-1

Pre-release. This build has not been tested on hardware yet, including key velocity sensing. Use it at your own risk; the author accepts no responsibility if your FM-1 is damaged or misbehaves. Release notes.

  1. Back up first: open the editor, connect, and save a backup (sounds, slots, settings).
  2. Connect the FM-1 directly to the computer with a USB data cable, and close other apps that use MIDI.
  3. Press Install and allow MIDI (SysEx) when Chrome or Edge asks. Do not unplug while it writes (about two minutes).


  
If it goes wrong: an interrupted install resumes: replug and press Install again (the FM-1
    stays in update mode until it is finished). If DAKHMEH crashes at start, hold OCT− while switching on for the
    USB rescue and install again. If even that is gone, the FM-1's boot ROM still updates with
    FM-1-transporter.
    From a terminal: python3 tools/fm1_install.py dakhmeh-.fwsc.
